# Metronome

A practice metronome for Android that trains your internal timing: it plays for a few bars, then goes silent for a few bars, so you can check whether you're still on the beat when the click comes back.

## Features

- **Phrase & gap training**: set a phrase length and how many of its last bars are silent
- **Spoken bar count**: "one, two, three…" at the start of each bar
- **Any time signature**: 1–16 beats, with 1, 2, 4 or 8 as the beat note (6/8 and 12/8 accented in groups of three)
- **Subdivisions**: eighths, triplets, sixteenths, dotted rhythms and more
- **Six click sounds**, per-beat muting, tap tempo
- **Keeps playing with the screen off**, with Play/Pause in the notification

## Install
1. Open the downloaded file on your Android phone (Android 7 or newer).                                                        2. If asked, allow your browser to **install unknown apps**.
3. If a **Play Protect** warning appears, tap **More details → Install anyway**.
   It shows up because the app isn't from the Play Store.

To update, install the new version over the old one; your settings are kept.
